Happy Halloween!

いくつかのバグを踏みつぶし、何匹かの怪物を追い払いました。

- チャンネル通知が「メンション」と「ミュート」を正しく扱うようになりました。公開チャンネルではどちらの設定も無視されていたため、何を選んでいても通知が届いていました。

- ミュートしたチャンネルはもう振動しません。以前はメッセージごとに一度振動し、無線機が再接続したときには溜まっていた分すべてで振動していました。

- オフにしていた通知音が鳴らなくなりました。

- メッセージの状態が、実際に起きたことを示すようになりました。チャンネルメッセージは無線機が送信を確認してはじめて送信済みとなり、mesh が報告する手段を持たない配信を主張することはありません。

- 送信できなかったメッセージは、チェックマークを表示するのではなく、その旨をはっきり示すようになり、ワンタップで再送できます。

- ホップ数とメッセージ長が、無線機自身が用いる単位で表示されます。63 ホップを超えられない mesh が 70 と称することはなくなりました。

- 下書きは、メッセージが送信され次第、入力欄から消えます。

- カスタム変数エディタが、変数を一つも持たない無線機でも開くようになり、最初の一つを作成できます。

- VoiceOver が時計で英語を話すことはなくなりました。

そして、新しいいたずらとお菓子もあります。

- 無線機ターミナル。無線機自身のコマンドラインが、ケーブル経由だけでなく Bluetooth 経由で使えるようになり、iPhone と iPad で初めて利用できます。「設定」の「高級」から、ファームウェア 1.18 以降で表示されます。

- オフラインで使える内蔵マニュアル。ネットワークを必要とするマニュアルは、必要なときにかぎって手に入らないからです。

- ノードを一つずつ並べるのではなく、横に並べて比較するセンサーダッシュボード。

- 発見した経路を mesh マップ上に描画し、各ホップを信号品質に応じて色分けします。

- ルームサーバーが独自のお知らせを掲示できます。

- 固定の区分ではなく種類セレクタを備えた単一の連絡先リスト。並べ替えと複数選択が、二つだけでなくすべてで使えるようになりました。

- MeshCore ファームウェア 1.18 に対応しました。

- 翻訳カタログに一度も届いていなかった 77 件の文字列を翻訳し、他の十一言語を見直して、欠けていたのではなく誤っていた訳を修正しました。

iPhone と iPad では長押し、Mac では右クリック。新しい操作はそこにあります。

- メッセージへの「クイックレスポンス」。ホップ数、信号、時刻、そして自分で決めた場所の名前を添えて返信でき、それぞれ個別に切り替えられます。

- 届かなかったメッセージの「送信の再試行」。

- 連絡先の「保持」で整理の対象から守り、「古い連絡先を検索」で応答しなくなった相手を見つけ出せます。

- 「連絡先リンクを貼り付けてください」で、クリップボードのリンクから相手を追加できます。

- 「フラッディングアドバタイズを送信」で、すぐ隣の相手だけでなく mesh 全体に自分を知らせます。
